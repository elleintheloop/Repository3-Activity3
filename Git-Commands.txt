CS223 - Activity 3: Repository Creation and Basic Git Commands

**1. Check repository status**
`git status`

**2. Stage the activity file**
`git add git-activity.txt`

**3. Commit the initial changes**
`git commit -m "Initial commit"`

**4. Push changes to the main branch**
`git push origin main`

**5. Create a feature branch**
`git branch feature-branch`

**6. Switch to the feature branch**
`git checkout feature-branch`

**7. Commit feature branch changes**
`git commit -m "Update git activity in feature branch"`

**8. Push the feature branch**
`git push -u origin feature-branch`

**9. Switch back to main**
`git checkout main`

**10. Merge the feature branch**
`git merge feature-branch`

**11. Pull remote changes**
`git pull origin main`

**12. Check available branches**
`git branch`

These commands demonstrate basic Git operations, branching, merging, and synchronization with GitHub.
